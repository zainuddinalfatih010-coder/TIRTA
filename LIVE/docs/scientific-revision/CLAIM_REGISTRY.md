# Claim and rule registry

Canonical executable records: src/domain/evidenceRegistry.ts and evidenceCatalog.ts.25 peer-reviewed journal records (20core,5reserve) plus4 separate method/standard/report/guidance records. Crossref publisher-deposited metadata and primary publisher material are retained in verification artifacts. No capacity is copied from articles as a default. Full normative SNI text is not claimed reviewed.

| Rule | Claim | Role / limit |
|---|---|---|
| CONNECTION | CLAIM-CONNECTION | Declared source access, never hydraulic simulation |
| CAPACITY | CLAIM-STORAGE | Nominal vs empty volume; no same-event refill credit |
| PERFORMANCE | CLAIM-LOCAL | Performance basis bound to current input and context |
| SOIL | CLAIM-SOIL | Infiltration evidence, no photo/texture-only numeric proof |
| GROUNDWATER / STANDARD | CLAIM-GROUNDWATER | Context review, no unverified numeric SNI cutoffs |
| MEDIA | CLAIM-BIO-MEDIA | Garden media/planting context, no construction guarantee |
| CONVERSION / SUBGRADE | CLAIM-POROUS | Impervious conversion, system dependency and no baseline double count |
| MAINTENANCE | CLAIM-MAINTENANCE | Known damage/clogging requires review |
| RESOURCE | CLAIM-LOCAL | Declared data/budget/land checks; the reference does not verify a price or site input |
| FIELD | CLAIM-FIELD | Site review/observational limits |
| LIMIT | CLAIM-VOLUME-LIMIT | Volume is not peak flow, ponding or flood prediction |

Other UI claims: CLAIM-VOLUME (unit conversion and coefficient volume relationship); CLAIM-VEGETATION (qualitative mechanisms only); CLAIM-ROOF (metadata, no automatic C); CLAIM-DURATION (average only); CLAIM-PARETO (three unweighted objectives, user decides).

ScientificReference displays brief scope/limitations before linked references. Full catalog is searchable in a native dialog. Controls and export use the same registry. Existing engineering references in the basic intervention form are preserved as historical scoped supporting references; the new registry is the authority for screening rules.
