# TIRTA

Teknologi Integrasi Resapan, Tampungan, dan Air Hujan.

Live app: https://tirta-c35.pages.dev/production.html

## Repository layout

- `LIVE/` — canonical web production source for Cloudflare Pages.
- `NATIVE/` — native Android/desktop packaging workspace and native-specific source.
- `AGENT/CURRENT/` — current engineering context/protocol documents.

Generated build outputs, caches, local credentials, signing keys, APK/EXE binaries, and QA artifacts are intentionally excluded from this public source repository.
